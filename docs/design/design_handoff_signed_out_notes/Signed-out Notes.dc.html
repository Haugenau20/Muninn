4Signed-out Notes: should it have an example? Yes.

Why: gated-page-copy.ts already calls notes "the one blurb that sells rather than describes". Extraction is the product's most persuasive feature, and a stranger has no other way to see it. Today the page is a bare panel. A list of example notes would show very little, so the example is one note opened in the editor, with the Campaign links panel beside it.

Content: a new, invented English note from the Ashen Vale, written in a player's rough session voice. Nothing comes from your notes. The names it mentions are the fixture's NPCs and places, so "In your campaign" shows them, and five new names (one of each type, including a quest and a rumour) appear under "Detected". There's no author anywhere, and the Smart detection usage card is left out, because a stranger has no allowance.

The scan never calls OpenAI. In 4b it replays canned results, so a visitor costs nothing and no text leaves the browser. The panel's "Sends this note's text to OpenAI" line changes to say so.

4aNotes · faithful. The real NoteEditor and CampaignLinksPanel, read-only, shown already scanned. "Add" is disabled.
